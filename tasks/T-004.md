# T-004 — .rodata candidate sweep (no patches, table only)

Status: done (Freebuff, 2026-11-10) · Owner: Freebuff · Priority: 3 · Effort: half day

## Why
Find real cheat addresses to replace the fabricated ones. We patch DATA
(constants in .rodata), not code — data survives the ppumod precompile.
Depends on T-002 (segment extraction + disasm pipeline) for addresses/context.

## Patterns to search (EBOOT LOAD segments, big-endian PPU)
- f32 frame-cap candidates: PPU stores big-endian, so
  30.0f (0x42F00000) = bytes `42 F0 00 00`; 60.0f (0x42C00000) = `42 C0 00 00`
- f64: 30.0 = `40 47 00 00 00 00 00 00`, 60.0 = `40 57 00 00 00 00 00 00`
- timing: 1/30 ≈ 0.0333… = `3D 2A AA AB`; 1/60 ≈ 0.0166… = `3D 2A AA AB`/2 → `3E 2A AA AB`
- int32 30 = `00 00 00 1E`, int32 60 = `00 00 00 3C`
- thresholds/gauges: 1.0f = `3F 80 00 00`, 0.5f = `3F 00 00 00`, -1.0f, 0xFFFE/0xFFFF flags

## Steps
1. `scripts/rodata_sweep.py` (run `-I`, args: seg dirs) → every hit:
   `(segment, offset, vaddr, pattern_id, 32-byte context hex)`.
2. For each hit, pull ±32 instructions of disasm (T-002 pipeline) into context.
3. Output `re/candidates.csv` + a `docs/candidates-rationale.md` ranking the
   top-5 per cheat slot in `docs/CHEAT-SPECS.md` (fill their Address/Old/
   New columns with candidate values, Status=`candidate`).

## Hard rules
- **No patch files, no `~/.config/rpcs3`, no game files.** Table + rationale only.
- Only candidates with plausible surrounding code context (near timing/gauge/
  flag logic) make the top-5; raw hits without context go in the csv but not
  the rationale doc.

## Report (Freebuff, 2026-11-10)

Branch `T-004` (from `T-003`). Repo-local only: `re/`, `docs/`, `scripts/`,
`tasks/`. No patches, no `~/.config/rpcs3`, no game files touched.

### What was built
- `scripts/rodata_sweep.py` — 15 big-endian patterns over both LOAD segments;
  per hit: `segment, vaddr, pattern, type, value, in_code, refs, ref_ops,
  context_hex`. `in_code` = hit inside a prologue-derived function range
  (`re/ppuanalyser/functions.csv`). `refs`/`ref_ops` = code→data references,
  with the access mnemonic (`lwz*3`, `lfd*117`, …).
- Two address-construction forms are detected: `lis`+`ori`/D-form within 6
  instructions, and r2-relative (`disp(r2)`), with `BASE_R2 = 0x019B0000`
  inferred from `lwz 7, -24984(2)` → `0x19a9e68` (the 120.0f table entry).
- Outputs: `re/candidates.csv` (4,585 hits), `re/references.csv` (124,520
  references), `docs/candidates-rationale.md` (top-5 + negative results).

### Findings
1. **The spec's float encodings were wrong** (all of them). `0x42F00000` is
   120.0f not 30.0f; `0x42C00000` is 96.0f; `0x3D2AAAAB` is 1/24 not 1/30;
   `0x3E2AAAAB` is 1/6 not 1/60; f64 30.0/60.0 were 46.0/92.0. The sweep was
   re-run with corrected bytes; corrected table in `docs/CHEAT-SPECS.md`.
2. **No `.rodata` constant is provably the frame cap.** 30.0f appears 86×, 82
   of them code-side; no address holds a 30/60 pair (checked all 30.0f hits
   against every 60.0f/120.0f hit, 0x100-byte window). Top probe is
   `0x19afbac` (30.0f passed as a callee argument at `0xe0d078`).
3. **`0x160bbf0` is a decoy**: 117 `lfd` readers, but the 8-byte record is the
   double 2^32 (`fcfid` follows) and the 30.0f match is its high half.
4. **The `1/60` data constants are physics, not rendering**: `0x19ad530` sits
   with `-9.8` (gravity) and is fed one-float-per-call to `0xf32408`;
   `0x19a8d88` is a `mtctr` integration step. Do not patch for 60 fps.
5. Other slots (`skip_intro`, `one_shot`, `heavy`, `burst`, `god`, `extras`)
   have **no** defensible `.rodata` candidate — their state lives in heap
   objects / state machines / save data. Left `TBD` rather than guessed.
6. Reference caveat: data blobs decode as plausible instructions, so a single
   reference can be spurious — `0x19a8384`'s only ref (`0x16803b0`) is a
   misdecoded byte-ramp table, verified by hand.

### Acceptance vs spec
- `re/candidates.csv` — done (all hits, with context + refs).
- top-5 ranked per slot — done for `cheat_60fps` (the only slot with data
  constants); explicitly empty for the rest, with reasons (§5 of rationale).
- hard rule "only candidates with plausible context make top-5" — enforced;
  the `0x160bbf0` rejection is the clearest case.
